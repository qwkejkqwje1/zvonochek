# ZVONochek — личный защищённый мессенджер и звонки в браузере

Чаты и звонки для своего круга, которые продолжают работать, когда основной
мессенджер заблокирован. Без регистрации, номера телефона и установки:
открыли ссылку — и вы на связи. Всё содержимое шифруется на устройствах;
серверы и ретрансляторы видят только шифротекст.

**Сайт:** https://qwkejkqwje1.github.io/zvonochek/ · версия **v41** ·
[что нового](CHANGELOG.md) · [выпуск и деплой](RELEASE.md) · [аудит v41](AUDIT-v41.md)

## Возможности

**Чаты** — в привычной раскладке Telegram:
- личные и групповые; ответы с цитатой, реакции, правка и удаление, закреп,
  поиск, черновики, «печатает…», «в сети», галочки доставки и прочтения;
- файлы до 25 МБ, картинки с автозагрузкой, голосовые сообщения;
- исчезающие сообщения по таймеру, удаление чата у себя или у всех,
  автоудаление чатов, молчащих 30 дней;
- вход по ссылке, короткой ссылке, одноразовому коду или кодовой фразе;
  PIN, который сообщают голосом, — без него не вычисляется даже адрес чата;
- предупреждение о каждом новом устройстве в чате (с хвостом его ключа);
- анонимные имена («Тихий Маяк») для вас, чатов и звонков, пока вы не
  ввели своё; «Пересинхронизировать шифрование», если что-то не открылось.

**Звонки:**
- аудио и видео 1:1 и группой до 6 человек (вход в звонок чата — нажатием
  на плашку), демонстрация экрана, файлы;
- «мост»: если прямое соединение невозможно и TURN нет, голос идёт через
  зашифрованный сигнальный канал;
- голос с защитой от потерь (Opus + RED) — не «булькает» в мобильной сети;
- щадящий режим для слабых телефонов: качество видео «Авто» по устройству,
  снижение при перегрузке процессора, перегреве и низком заряде; свернули
  звонок — собеседник перестаёт слать видео;
- код сверки (эмодзи + цифры) против подмены собеседника;
- живая статистика: оценка качества (MOS), задержка, потери, джиттер,
  битрейт, видео, маршрут и канал, который первым доставил сигнал;
- журнал и сводка за 30 дней: разговоры, время на связи, качество, маршруты.

**«Мой номер»** — постоянная личная ссылка: вам звонят с громким рингтоном,
как по номеру телефона, даже когда приложение закрыто (push: Android, ПК,
iPhone с приложением на главном экране). Пропущенные звонки; контакты и
обратный звонок из «Недавних»; «Сменить номер» (старая ссылка перестаёт
работать) и «Стереть всё». Резервная копия личности и списка чатов — по
фразе из 17 слов.

**Несколько устройств** — как «Связанные устройства» Signal: телефон, ПК и
планшет с одним номером, чатами, контактами, журналом и настройками.
Подключение — QR или 12-значный код и сверка 4 контрольных слов, по желанию
с историей переписки за 45 дней. Звонок на номер звонит на всех
устройствах, свои сообщения с другого устройства — «мои». Собеседники видят
новое устройство как ваше, подтверждённое ключом профиля. Подключать,
отвязывать устройства и менять номер можно только с основного устройства.

Работает как PWA: устанавливается на главный экран, оболочка открывается
офлайн, интерфейс — тёмная тема для телефона и двухпанельная раскладка на ПК.

## Как это устроено

```
 Браузер A ──── медиа: P2P (DTLS-SRTP) · TURN · мост ──── Браузер B
     │                                                     │
     └──── сигнал и чат: шифротекст, параллельно 5 каналов ┘
           1. Cloudflare Worker — WebSocket (основной)
           2. Cloudflare Worker — HTTP-поллинг (если WS режут)
           3. 5 публичных MQTT-брокеров по WSS (в т. ч. порт 443)
           4. 9 публичных Nostr-реле (для чата — хранимая лента)
           5. ntfy.sh (только «живая» доставка)
```

- Каналы работают одновременно: побеждает самый быстрый, дубли
  отбрасываются по идентификатору сообщения. Отказ одного канала не рвёт
  звонок и чат — история досинхронизируется, когда основной сервер вернётся.
- Звонок начинается с прямого соединения (5 STUN-серверов). TURN (Metered
  и ExpressTURN, логины в `config.js`; при желании — ещё и из своего
  Worker) — крайнее средство: подключается, только если прямой путь не
  поднялся за 6 с (v40: пока ICE заметно продвигается — ждём до 14 с) или
  упал, и не тратит лимиты, пока он не нужен. Если не работает ничего — мост.
- Worker — «слепой» релей на Durable Objects: комнаты сигналинга (Room),
  чаты (ChatRoom), дозвон и пропущенные (Inbox), коды и резервные копии
  (Pairing).
- Сборки нет: статические ES-модули, без runtime-зависимостей. Потолок
  синтаксиса — ES2020 (старые Android-телефоны), это проверяют тесты.

| Модуль | Назначение |
|---|---|
| `app.js`, `group.js` | звонок 1:1 и групповой mesh, мост, TURN, журнал |
| `signaling.js`, `mqtt-lite.js`, `ntfy.js` | мультиканальный сигналинг; свой MQTT 3.1.1-клиент на ~300 строк |
| `chat.js`, `chat-transport.js` | мессенджер и его резервные каналы |
| `crypto.js`, `identity.js`, `backup.js` | криптография, личность и устройства, резервная копия |
| `devices.js`, `sync-core.js` | «Мои устройства»: привязка, синхронизация профиля, отвязка и rekey; чистая логика слияния |
| `callstats.js`, `stats-ui.js` | статистика звонка: чистая логика и отрисовка |
| `media-policy.js` | сколько видео снимать, кодировать и принимать на этом устройстве; порядок кодеков |
| `inbox.js`, `store.js`, `coalesce.js` | дозвон, IndexedDB, схлопывание перерисовок |
| `zvdiag.js`, `sw.js`, `config.js` | ранняя диагностика, Service Worker (push, офлайн), настройки |
| `anon-names.js` | анонимные имена из id |
| `worker/` | Cloudflare Worker: `worker.js`, `chat-room.js`, `inbox.js`, `pairing.js`, `push.js` |

## Безопасность

**Что защищено**
- Ключи создаются и живут только на устройствах. Ключ звонка и чата — во
  фрагменте ссылки после `#`, браузер не отправляет его на сервер.
- Сигнал, голос моста и сообщения — AES-256-GCM, ключи выводятся через
  HKDF-SHA256 из 256-битного секрета. Медиа WebRTC — DTLS-SRTP.
- Сообщения подписаны ключами устройств (ECDSA P-256) и шифруются
  одноразовыми ключами храповика: утечка ключа сегодня не открывает
  вчерашнюю переписку (forward secrecy).
- Сервер хранит шифротекст фиксированного размера (длина сообщений не видна)
  и только хэш токена доступа; сообщения удаляются, когда их забрали все
  участники (не раньше 7 дней), максимум через 30 дней; неактивный чат —
  через 30 дней. Брошенные номера, алиасы и копии тоже чистятся сами.
- Коды, короткие ссылки и кодовые фразы защищены PBKDF2 (200–600 тыс.
  итераций), а с v36 из медленного KDF выводится и адрес записи — перебор
  по адресам на сервере больше не дешевле перебора ключа.
- В настройках звонка есть режимы «Скрыть мой IP — только через TURN» и
  «Только мост», чтобы собеседник не видел ваш IP-адрес (v40: в режиме
  моста звонок 1:1 больше не рассылает свои адреса; в групповом звонке
  моста нет — там работает только «через TURN»).

**Чего ZVONochek не скрывает — честно**
- **Метаданные.** Cloudflare (Worker) и публичные брокеры/реле видят
  IP-адреса, время и объём трафика, хэш-идентификаторы комнат. Nostr-реле
  хранят зашифрованные события публично. Кто с кем и когда общается, можно
  оценить по трафику; скрыть это помогает VPN/Tor на стороне пользователя.
- **Прямой звонок раскрывает IP собеседнику** (так устроен WebRTC) — для
  этого и есть режимы «только TURN» и «только мост».
- **Push-службы** (Google, Apple, Mozilla) видят время уведомлений и что
  они идут на ваше устройство; содержимого в push нет.
- **«Сменить номер»** отрезает звонящих по старой ссылке, но сервер может
  связать старый и новый номер (то же устройство, push-адрес, IP). Полный
  разрыв — «Стереть всё» и новая установка.
- **Подключённое устройство — полноправное**, пока его не отвязали: читает
  синхронизируемые чаты и пишет от вашего имени. Подключайте только своё
  устройство в руках — никогда по QR или коду, который прислали. Украли
  устройство — «Отвязать» сразу, затем «Сменить номер». Сервер видит,
  какие устройства делят комнату синхронизации, но не её содержимое.
- **Логины TURN публичны** (решение владельца на время беты): чужие могут
  выбрать бесплатную квоту — тогда звонки через «жёсткий» NAT уйдут в мост.
  Лечится заменой логинов в `config.js`.
- **Ссылка = доступ.** Кто получил ссылку, тот в чате. Передавайте ссылку
  одним каналом, а PIN — голосом; сверяйте код звонка; следите за
  предупреждениями о новых устройствах.
- **Доверие к сайту.** Веб-приложение загружается с хостинга: кто управляет
  репозиторием или хостингом, может подменить код. Для максимальной
  независимости разверните свою копию сайта и Worker (см. ниже).
- **Блокировки.** Если заблокированы и сайт, и все каналы, нужен VPN хотя бы
  для первого открытия; установленное приложение открывается офлайн, но для
  связи нужен хотя бы один доступный канал.
- **Устройство.** Взломанный телефон или вредоносное расширение браузера
  видят всё, что видит пользователь.
- Независимого внешнего аудита не было; в полях проверено на ограниченном
  наборе сетей. Подробности и остаточные риски — в [AUDIT-v39.md](AUDIT-v39.md).

## Как пользоваться

1. **Чат:** «Чаты» → ✏️ → имя → «Пригласить» или «Копировать ссылку».
   Для важных чатов задайте PIN и сообщите его голосом.
2. **Звонок по ссылке:** «Звонки» → «Новый звонок» → отправить ссылку.
   В звонке сверьте код (иконка щита) голосом.
3. **Постоянный номер:** «Мой номер» → «Создать мою ссылку» → раздайте её
   своим. Разрешите уведомления — тогда звонок дойдёт и в закрытое
   приложение. Включите резервную копию и запишите 17 слов на бумагу.
   Кто вам звонил — в «Звонки» → «Недавние звонки»: кнопка обратного звонка
   и «Сохранить» в контакты.
4. **Второе устройство:** на нём «Мой номер» → «Подключить к моему
   профилю»; на основном — «Мой номер» → «Мои устройства» → «Подключить
   устройство» → отсканировать QR или ввести код → сверить слова.
5. Установите приложение на главный экран — так оно открывается быстрее и
   работает офлайн.

Рекомендуется для своего круга: данные будут только на вашем аккаунте
Cloudflare (бесплатного тарифа хватает).

## Разработка

Нужен Node.js ≥ 22.

```bash
npm ci
npm test                 # юнит- и статические тесты (node:test)
npm run worker:dev       # локальный Worker на 127.0.0.1:8787
npm run e2e              # несколько браузеров: чат, звонок, номер, устройства (нужен Chromium)
```

- `npm run e2e` поднимает статический сервер на `127.0.0.1:8765`, открывает
  два профиля Chromium и проверяет чат (сообщения, реакция, ответ, список)
  и звонок (соединение, статистика, кодек «Opus + RED», режим видео,
  ограничение качества при свёрнутом окне и его снятие, журнал)
  на телефоне и ПК, а также «номер» (звонок по личной ссылке, контакты,
  смена номера, «Стереть всё») и «профиль» (второе устройство: привязка по
  коду, синхронизация чатов, контактов и истории, смена номера на обоих
  устройствах, отвязка).
  Переменные: `CHROMIUM_PATH`, `WORKER_URL`, `VIEWPORTS`, `SHOTS=1`,
  `ONLY=чат|звонок|номер|профиль`, `DEBUG=1` (консоль страниц, ответы
  HTTP ≥ 400 и время шагов).
- Статические тесты следят за целостностью: все `#id` из JS есть в HTML,
  иконки существуют, версии совпадают во всех файлах, Service Worker
  кэширует все модули, синтаксис укладывается в ES2020.
- CI: `.github/workflows/ci.yml` (GitHub Actions, бесплатно для публичного
  репозитория) на каждый push и pull request запускает `npm test`, а затем
  e2e с локальным Worker (`wrangler dev`) и Chrome.
- Новая версия: поднять `APP_VERSION`/`APP_BUILD` в `app.js`, `?v=` во всех
  импортах и `index.html`, `CACHE_NAME` в `sw.js`, `version.json`,
  `package.json`; `npm test` подскажет, если что-то забыто.
