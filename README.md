# 📞 ZVONochek v11 (Ultimate Anti-Block Edition)

Защищённые портативные аудио- и видеозвонки по ссылке прямо в браузере. Без регистрации, без аккаунтов и без установки.

**Открыть:** https://qwkejkqwje1.github.io/zvonochek/

## Что нового в версии v11
- **🛡️ Режим «Мост через Сигналинг» (Работа вообще без TURN и при блокировке UDP):** если мобильный оператор или файрвол блокирует WebRTC/UDP, а TURN-сервера нет, звонок автоматически (через 7,5 с) или по нажатию кнопки **«🛡️ Включить мост без TURN»** переключается на передачу сжатого голоса Opus (14 Кбит/с) и чата напрямую через зашифрованные каналы сигналинга (WSS / HTTPS).
- **📡 Четырёхканальный сигналинг с дедупликацией и буфером рукопожатий:**
  1. Публичные **MQTT-брокеры** по WSS (включая порт 443).
  2. **Cloudflare Worker WebSocket** с автоматической ротацией окна каждые 9 КБ (обход заморозки ТСПУ на 16 КБ) и кольцевым буфером последних сообщений в `Room` (исключает потерю `offer`, если собеседник открыл ссылку позже).
  3. **Cloudflare Worker HTTP-поллинг (`GET / POST`)** — автоматически подхватывает связь, если в сети заблокирован заголовок `Upgrade: websocket`.
  4. **Nostr-реле** на порту 443 (подписанные эфемерные события `secp256k1`).
- **🎛️ Аудио-микшер и настройки звука как в Discord:**
  - Независимая регулировка **громкости собеседника (0% — 200%)** с усилением тихого звука (Web Audio API `GainNode` + `DynamicsCompressorNode`).
  - Регулировка **усиления микрофона (0% — 200%)** и кнопка **«🔊 Проверить микрофон»** (Loopback-тест).
  - **Два режима ввода:** «🎙️ Активация по голосу (VAD)» с живой шкалой дБ и настраиваемым порогом отсечения фонового шума (`-75 … -15 дБ`) и «📻 Рация (Push-to-Talk)» (по кнопке на экране или клавише `Пробел`).
  - Кнопка **«🎧 Оглушить (Deafen)»** и зелёное кольцо активности голоса вокруг аватара говорящего.
  - Настройка битрейта **Opus** (`12 / 24 / 48 / 64 Кбит/с`) с принудительным включением коррекции потерь (`useinbandfec=1`) и экономии трафика в тишине (`usedtx=1`).

## Шифрование и безопасность
- **Медиапоток WebRTC:** DTLS-SRTP напрямую между браузерами.
- **Сигналинг и голосовой мост:** AES-256-GCM (ключ выводится через HKDF-SHA256 из 256-битного секрета `#k=...` во фрагменте ссылки, который никогда не передаётся на сервер).
- **Код безопасности:** 5 эмодзи + 6 цифр (SHA-256 от отпечатков ключей обеих сторон) для защиты от перехвата (MITM).
