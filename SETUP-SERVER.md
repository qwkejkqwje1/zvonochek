# Свой сервер за 2 минуты

ZVONochek состоит из двух частей:

- **Клиент** (сайт) — статические файлы на GitHub Pages, общий для всех.
- **Воркер** (серверная часть) — Cloudflare Worker: сигналинг звонков, чат,
  дозвон (Inbox), коды подключения и резервные копии. По умолчанию приложение
  ходит в воркер владельца проекта. Эта инструкция — как поднять **свой**
  воркер и подключить приложение к нему. Все ваши комнаты, сообщения и
  бэкапы тогда будут жить только на вашем аккаунте Cloudflare.

## Шаг 1. Развернуть воркер одной кнопкой

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/qwkejkqwje1/zvonochek)

1. Нажмите кнопку выше.
2. Войдите в свой аккаунт Cloudflare (бесплатный тариф достаточен; если
   аккаунта нет — регистрация занимает минуту).
3. Cloudflare сам клонирует репозиторий и покажет настройки деплоя:
   имя воркера по умолчанию `zvonochek`, конфиг возьмётся из корневого
   `wrangler.toml` (все Durable Object — Room, Inbox, ChatRoom, Pairing —
   и миграции уже описаны там).
4. Нажмите **Deploy** и дождитесь окончания (обычно до минуты).

## Шаг 2. Взять адрес своего воркера

После деплоя Cloudflare покажет адрес вида:

```
https://zvonochek.<ваш-аккаунт>.workers.dev
```

Это и есть адрес вашего сервера. Проверка: откройте в браузере
`https://zvonochek.<ваш-аккаунт>.workers.dev/health` — должен ответить JSON
со статусом и версией воркера.

## Шаг 3. Указать адрес в приложении

1. Откройте ZVONochek → **Настройки** → раздел **«5. Свой сервер»**.
2. Вставьте адрес своего воркера и нажмите **«Применить сервер»**.
3. Готово: чат, дозвон, коды подключения, бэкапы и Worker-сигналинг звонков
   теперь ходят в ваш воркер. Кнопка «Сбросить на сервер по умолчанию»
   возвращает общий воркер проекта.

## Что нужно знать честно

- **Сайт (клиент) остаётся общим** — он статический и одинаковый у всех;
  в ваш воркер идут только данные. Если разворачиваете и свою копию сайта
  (форк + GitHub Pages), поправьте в своём воркере переменную
  `ALLOWED_ORIGINS` на адрес вашего сайта: воркер принимает запросы только
  с разрешённых адресов.
- **Смена сервера не переносит данные.** Комнаты чатов, коды, бэкапы и
  пропущенные звонки живут на том сервере, где созданы. Личные ссылки и
  seed-ы комнат при этом те же самые — просто на новом сервере комнаты
  пусты, пока в них не напишут.
- **Необязательный шаг — push-уведомления при закрытом приложении.**
  Для них воркеру нужен секрет `VAPID_PRIVATE_JWK` (раздел переменных и
  секретов воркера в панели Cloudflare). Без него всё работает, кроме
  уведомлений при полностью закрытом приложении: пока приложение открыто,
  уведомления о сообщениях и звонках приходят и так.
- **TURN для звонков** — тоже необязательно: без TURN-кредов звонки идут
  напрямую (P2P) и через мост. Собственные TURN-креды задаются переменными
  воркера, см. `worker/README.md`.
