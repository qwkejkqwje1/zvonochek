# ZVONochek v20 — личный коммуникатор: ссылка, дозвон, рингтон, push

Дата: 27 октября 2026. Реализация этапов 1–3 техплана коммуникатора
(ZVONochek-TECHPLAN-v15.md) одним выпуском; этап 4 (политики приёма)
и экспорт/импорт бэкапа идентичности — следующие шаги.

## Что появилось

- **Идентичность** (`identity.js`, `store.js`): master-ключ ECDSA P-256
  (невыгружаемый, IndexedDB), ключ устройства с master-сертификатом,
  секрет личной ссылки зашифрован vault-ключом. Личная ссылка формата
  `#k=<секрет>&d=<отпечаток master-ключа>`; старые клиенты откроют её
  как обычную комнату.
- **Главная**: блок «Личный коммуникатор» — создать ссылку, копировать/
  поделиться, статус доступности, уведомления, пропущенные, журнал
  недавних звонков (локально, IndexedDB).
- **Inbox Durable Object** (`worker/inbox.js`, SQLite, миграция v2):
  регистрация устройств с проверкой цепочки подписей, ring-состояния
  (ringing → accepted/declined/cancelled/expired, гонки закрыты атомарным
  UPDATE), пропущенные на 24 ч, listen-WebSocket для открытых приложений,
  alarm: push через 3 с без ack, истечение через 90 с. Лимиты: ≤30 ring/час
  на комнату, ≤10/час от одного звонящего, ≤8 подписок.
- **Дозвон**: по личной ссылке в лобби — кнопка «Позвонить владельцу».
  Звонящий шлёт зашифрованный blob (ключ комнаты, AES-GCM) через Inbox,
  параллельно занимает комнату; владелец принимает в обычном звонке.
  У владельца при открытом приложении — модалка входящего с рингтоном
  (WebAudio) и вибрацией; ack гасит push именно этому устройству.
- **Web Push** (`worker/push.js`): RFC 8291 aes128gcm + VAPID RFC 8292
  на чистом WebCrypto. **Проверено тестовым вектором RFC 8291 Appendix A —
  совпадение байт-в-байт** (ECDH, IKM, CEK, nonce и весь шифротекст).
  Payload пуша — только `{t, topic, ringId}` (ADR-3): push-служба не видит
  имён. SW: показ уведомления, ring-done закрывает уведомление на других
  устройствах, notificationclick открывает приложение.

## Что нужно сделать владельцу для включения (один раз)

1. Передеплоить Worker из репозитория (wrangler deploy) — подтянутся
   миграция v2 (класс Inbox) и новые файлы worker/inbox.js, worker/push.js.
2. Добавить секрет Worker `VAPID_PRIVATE_JWK` (значение выдано отдельным
   файлом, в репозитории его нет). Без секрета работают дозвон при открытом
   приложении и пропущенные; push при закрытой вкладке — нет.
3. На каждом своём устройстве: открыть сайт → «Создать мою ссылку» →
   «Включить уведомления о звонках» (на iPhone — сначала установить PWA
   на домашний экран, iOS ≥ 16.4, иначе Web Push недоступен в принципе).

## Честные ограничения

- Push — самая рискованная часть (этап 0 техплана требовал спайк на живых
  устройствах): крипто проверено вектором, но доставка на реальный Android/
  iPhone не тестировалась — нужен полевой прогон по чек-листу этапа 3.
- «Только контакты», чёрный список в UI, экспорт/импорт бэкапа, перевыпуск
  ссылки одной кнопкой — этап 4, не в этом выпуске (таблица blocked в Inbox
  уже есть, заполнять пока нечем из UI).
- Имя звонящего в blob — самозаявленное; подпись владельца в hi и сверка
  отпечатка из техплана (раздел 2.2) — частично: отпечаток показывается
  на экране входящего, автоматическая проверка подписи в hi — следующий шаг.
