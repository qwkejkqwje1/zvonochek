# Выпуск v38 — что сделать владельцу

Порядок: **Worker → сайт → проверка.** В v38 Worker обновлять
**обязательно**: в нём исправлены ошибки, из-за которых звонящий на
«Мой номер» не узнавал, что звонок приняли, дозвон участнику чата не
работал вообще, а push без ручного ключа был выключен
(подробно — [AUDIT-v38.md](AUDIT-v38.md)). Worker v38 совместим со старыми
клиентами (v32+), поэтому его можно выкатить первым.

## 1. Worker v38

```bash
npx wrangler deploy        # из корня: wrangler.toml → worker/worker.js
```

Проверка: `https://<ваш-worker>/health` →
`"v": 38, "push": true, "pushRepeat": true, "retention": "v38"`.
`"turn": false` — нормально: TURN идёт из `config.js`.

Ничего настраивать не нужно:

- **Push работает сам.** Если секрет `VAPID_PRIVATE_JWK` не задан, Worker
  при первом запросе создаёт ключ и хранит его в служебном Durable Object.
  Если позже задать свой секрет, ключ сменится. Клиенты заметят это при
  следующем запуске и переподпишутся сами, но до этого push на них не
  дойдёт. Если секрет уже был задан раньше, он остаётся в силе.
- **Автоочистка** включается сама при первом обращении к каждой записи:
  - чаты и файлы — 30 дней без сообщений;
  - алиасы — 30 дней без использования;
  - входящие «Моего номера» — 30 дней простоя (с push — 90);
  - резервные копии — 180 дней без обновления.
  
  Полная таблица — в [CHANGELOG.md](CHANGELOG.md).

## 2. Публикация сайта

Залейте содержимое архива в ветку `main` (GitHub Pages обновится сам, файл
`.nojekyll` нужен). Проверка: `…/zvonochek/version.json` → `{"v":38}`.
Открытые вкладки перейдут на новую версию при следующем открытии, Service
Worker сменит кэш на `zvonochek-v38`. При первом открытии каждого чата
v38 один раз «лечит» историю: расшифровывает сообщения, которые старые
версии потеряли. Это идёт фоном, без уведомлений.

## 3. Звонки при закрытом приложении — на каждом устройстве

1. **Android:** «Мой номер» → «Push-уведомления о звонках» (или кнопка
   «Включить» на плашке во вкладке «Звонки») → разрешить. На Xiaomi,
   Huawei, Honor и Samsung с агрессивной экономией батареи — исключить
   Chrome из оптимизации батареи, иначе push может опаздывать.
2. **iPhone:** сначала «Поделиться» → «На экран Домой», открыть ZVONochek с
   иконки и только потом включить уведомления (iOS ≥ 16.4; в Safari-вкладке
   push на iPhone не работает).
3. **ПК:** браузер должен быть запущен (вкладку можно закрыть).

Дальше подписка проверяется при каждом запуске автоматически.
На **выключенный** телефон звонок не дойдёт ни в одном мессенджере —
уведомление о сообщении придёт, если телефон выйдет в сеть в течение 6 ч.
Звонок ждёт только, пока идёт вызов (до 90 с), потом он попадает в
«Пропущенные» (хранятся 24 ч).

## 4. TURN — крайнее средство (решение владельца)

Звонок начинается **без TURN** (только прямой путь через STUN). Логины
Metered и ExpressTURN из `config.js` → `EXTRA_ICE_SERVERS` включаются,
только если:

- прямой путь не поднялся за 6 с;
- соединение упало;
- после смены сети не нашлось прямого пути;
- в настройках выбран режим «только TURN».

Пока прямой путь работает, к TURN нет даже аллокаций, и лимиты не
тратятся. Цена — до 6 с ожидания на старте в сетях, где прямой путь
невозможен (мобильный CGNAT у части операторов). Если не работает и TURN,
голос идёт мостом.

Логины видны всем в публичном репозитории. Если чужие выберут квоту,
зарегистрируйтесь бесплатно на metered.ca или expressturn.com, впишите новые
логины в `config.js` и опубликуйте сайт. Спрятать логины можно в секретах
Worker (`TURN_URLS`, `TURN_USERNAME`, `TURN_CREDENTIAL`, см.
[worker/README.md](worker/README.md)).

## 5. Откат

- **Только внешний вид:** «Настройки» → «Оформление» → «Классическое»
  (на каждом устройстве, мгновенно).
- **Весь сайт:** залить архив v37 в `main`. Worker v38 откатывать не нужно,
  клиент v37 с ним работает (и даже лучше: исправленные маршруты помогают
  и ему).

## 6. Проверка после выпуска (10 минут)

1. **«Мой номер», два устройства владельца + звонящий:** принять на одном
   устройстве. У звонящего — «Владелец принял звонок», второе устройство
   сразу замолкает.
2. **Закрытая вкладка (Android):** закрыть ZVONochek, заблокировать экран,
   позвонить на личную ссылку. Должно прийти уведомление с вибрацией,
   «Ответить» — и вы сразу в звонке.
3. **Дозвон из чата:** в чате 1:1 — кнопка звонка в шапке, в группе —
   📞 у участника в списке. У него звонит телефон (или приходит push), а не
   только строка в ленте.
4. **Группа из 3 человек:** начать звонок в чате. Остальные входят нажатием
   на плашку. Переход в чат и обратно не выкидывает участников.
5. **Доставка:** телефон в авиарежиме на 10 минут, в группе пишут двое.
   После включения всё докачивается, без «не удалось расшифровать».
6. **Рингтон:** «Настройки» → «Оформление» → «Проверить рингтон» — громко,
   с вибрацией.
7. **Контакты:** после звонка на личную ссылку в «Недавних звонках» есть
   кнопка обратного звонка, а «Сохранить» добавляет номер в «Контакты».
8. **Маршрут:** «Качество связи» в обычной сети — P2P. TURN — только там,
   где прямого пути нет (журнал диагностики: «TURN в резерве…»).

Перед публикацией разработчику: `npm ci && npm test` (и при наличии
Chromium — `npm run worker:dev` + `npm run e2e`).
